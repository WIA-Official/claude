# 🧠 WIA Neural Code

**Beautiful QR Code Alternative with Neural Network Visualization**

"30년 앞선 QR 코드 대체 시스템"

---

## 🎯 What is WIA Neural Code?

WIA Neural Code는 전통적인 QR 코드의 **격자 패턴**을 **아름다운 뉴럴 네트워크**로 대체한 차세대 데이터 인코딩 시스템입니다.

### ✨ 특징

- 🎨 **아름다운 비주얼**: 살아있는 듯한 뉴럴 네트워크 애니메이션
- 🔒 **QR 호환**: 표준 QR 마커로 안정적 감지
- 💾 **데이터 인코딩**: Alpha 채널을 활용한 효율적 인코딩
- 🌍 **211개 언어**: 전세계 모든 언어 지원
- 📱 **27가지 타입**: 텍스트, URL, WiFi, vCard, 결제 등

## 🚀 Quick Start

### Generator
```
https://wiacode.com/generate-wialanguages-code-BEAUTIFUL-NEURAL.html
```

1. 데이터 타입 선택 (텍스트, 링크, WiFi 등)
2. 데이터 입력
3. 실시간 미리보기 확인
4. 생성 버튼 클릭
5. 다운로드!

### Scanner
```
https://wiacode.com/mobile-scanner.html
```

1. 이미지 업로드 또는 카메라 스캔
2. 자동으로 QR 마커 감지
3. 뉴런 데이터 디코딩
4. 원본 데이터 복원!

## 🔑 핵심 기술

### 1. Canvas 크기 통일
Generator와 Scanner 모두 **480x480** 고정

### 2. 미리보기 = 다운로드
별도 생성 없이 미리보기 Canvas를 그대로 다운로드

### 3. Alpha 기반 인코딩
- 색상: RGB(102, 126, 234) 고정
- 데이터: Alpha 채널 (0.5~1.0)

### 4. 레이어 구조
4개 레이어: 8-12-16-20 = 총 56개 뉴런
